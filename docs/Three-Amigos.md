# Simulación Three Amigos

## Funcionalidad
Inicio de sesión.

## Roles
- Negocio/Product Owner: define el comportamiento esperado.
- Desarrollo: define la implementación.
- QA: define escenarios y criterios de prueba.

## Criterios de aceptación
1. Un usuario registrado puede iniciar sesión con credenciales válidas.
2. Una contraseña incorrecta debe impedir el acceso.
3. El sistema debe informar el resultado de la autenticación.

## Ejemplos
- admin / 123456 -> acceso.
- admin / 999999 -> rechazo.
